# Shophippy — VS Code Project

## How to open in VS Code Desktop

1. Download the ZIP `shophippy-vscode.zip`
2. Unzip it
3. Open VS Code → File → Open Folder → select `shophippy-vscode`
4. Open terminal in VS Code (Ctrl+`):

   npm install
   npm run dev

5. Open http://localhost:3000. The dev command starts the Vite site and quote API.

## Neon quote requests

The quote form stores submissions in the linked Neon Postgres database only after the visitor agrees to be contacted. The database connection stays on the server; do not expose `DATABASE_URL` in browser code.

- `.env.local` is generated by `neon init` and is ignored by Git. Keep it private.
- Run `npm run migrate` after Neon setup to create `public.quote_requests` using the direct `DATABASE_URL_UNPOOLED` connection.
- `npm run dev` starts the app and API. Check the API/database connection at http://localhost:3001/api/health.
- For production, run `npm run build`, then `npm start`; configure `DATABASE_URL` in the host environment.
- `npm run build` copies the embedded standalone site into the production bundle.

## Structure
- `static-build.html` - Fully built standalone version (you can open directly or with Live Server)
- `src/` - React source (Vite + React)
- `../package.json` - workspace scripts for running commands from the project root
- `package.json` - app dependencies and Vite configuration

The Vite app includes the USD/PKR quote budget selector and Sara, a local virtual project guide. PKR ranges are approximate USD equivalents using PKR 276.95 per USD (rate checked Nov 11, 2026); the final quote may differ. The standalone HTML is an original static snapshot; use `npm run dev` for these interactive features.
